# Shubham Bhavsar — Portfolio

> Personal portfolio website for **Shubham Bhavsar**, Full Stack Blockchain Developer.

**Live:** [portfolio_3D on GitHub](https://github.com/BhavsarShubham/portfolio_3D)

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | React 18 + Vite |
| Styling | Tailwind CSS |
| Animations | Framer Motion |
| 3D | Three.js · React Three Fiber |
| Contact Form | Web3Forms |
| Deployment | Vercel |

---

## Sections

- **Hero** — Animated network canvas, gradient headline, CTAs
- **About** — Engineering summary + journey timeline
- **Experience** — Interactive expandable timeline (Timechain Labs)
- **Projects** — Hackathon winner card + project grid
- **Skills** — Filterable tech stack with proficiency bars
- **GitHub** — Live GitHub API repo fetch
- **Achievements** — Certifications with certificate preview popups
- **Philosophy** — BUILD · TEST · DEBUG · SHIP · LEARN
- **Contact** — Contact form + social links + 3D Earth

---

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Production build
npm run build
```

Dev server runs at `http://localhost:5173`
